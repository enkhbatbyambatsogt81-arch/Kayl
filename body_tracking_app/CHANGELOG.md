# Хувилбарын түүх

## 3.0 — Тогтвортой ажиллагаа

**Анивчихгүй болсон**
- Бодит камерт (гэрэл, зай, камерын чанараас хамаараад) бие кадрын ирмэгт ойрхон байхад «Бүтэн бие кадрт
  багтсан» шалгалт кадр бүрт ✓ / ✗ болж, шалгах жагсаалт, зөвлөмжийн бичиг, эхлэх хүлээлтийн зураас секундэд
  хэдэн арван удаа солигдож анивчдаг байсан. Одоо шалгалт 0.4 секундээс удаан алдагдвал л «алдагдсан» болно,
  шинэ зөвлөмж 0.2 секунд тогтвортой байж, өмнөх нь 0.6 секундээс удаан харагдсан бол л солигдоно. Шат солигдох,
  давталт тоологдох үед шууд солигдоно (`WorkoutConfig.settle_seconds`, `message_settle`, `message_hold`).
- Цонхны тодорхой өргөн, өндөрт (жишээ нь 1366×768, 125%) дасгалын картын зураг ба дасгалын самбарын
  хэмжээ гарч/нуугдаж солигдон анивчиж болох байсныг 2 босготой болгосон. Графикууд цонхны хэмжээ
  өөрчлөгдөхөд нэг л удаа дахин зурагдана.

**Интерфейс**
- «Нарийвчилсан тохиргоо» нь хүрээтэй, дүрстэй товч болсон (өмнө нь энгийн бичиг шиг харагддаг байсан).
- Сонгосон дасгал, түвшний карт дахин **цэнхэр хүрээ**, цэнхэр «Сонгосон» / ✓ тэмдэгтэй.
- Эхлэх хуудасны «Зөв гүнд хүрсэн» шошгыг хассан.
- Зүүн цэсний «Хэмжээ» цэсийг хассан. Оронд нь аль ч хуудсанд `Ctrl +` / `Ctrl −` томруулж / жижигрүүлнэ
  (80–200%), `Ctrl 0` нь 100% руу буцаана (macOS: `⌘`). Хэмжээ солигдоход доод талд богино мэдэгдэл гарна.

**Тест:** 88 (шинэ: шуугиантай камерт шалгах жагсаалт, зөвлөмж анивчихгүй; товчлуураар томруулах).

## 2.4 — Горим солих товч, «Гар дээр суниалт»

- Цайвар / харанхуй горимыг **хуудас бүрийн баруун дээд буланд** байх товчоор солино (эхлэх урсгал, тохиргоо,
  дасгал хийх, дүн, түүх, заавар). Мөнгөлөг гулсуур дээрх бөмбөлөг цайварт нартай зүүн талд, харанхуйд сартай
  баруун талд гулсана; харанхуй горимд зөөлөн гэрэлтэнэ. Зүүн цэсний «Өнгөний горим» хэсгийг хассан.
- Push-up-ын нэрийг «Шалнаас түлхэлт»-өөс **«Гар дээр суниалт»** болгосон (товчоор «Суниалт»).

**Тест:** 86 (GUI тест горим солих товчийг шалгадаг болсон).

## 2.3 — Эхлэх урсгал, мэргэжлийн нэршил, татаж ажиллуулах файл

**Эхлэх урсгал**
- Апп тохиргоо ихтэй хуудсаар биш, **Эхлэх** хуудсаар нээгдэнэ: «Эхлэх» → **түвшин** → **дасгал** → камер.
  Алхам бүрт явцын зураас («Алхам 1 / 3»), «← Буцах», «Үргэлжлүүлэх» товч бий. `Enter` дараах, `Esc` буцах,
  `1`–`3` түвшин, `1`–`2` дасгал сонгоно.
- Түвшин: **Анхан шат** (2 × 8, уян шалгуур), **Дунд шат** (3 × 10, стандарт, зөвлөмж), **Ахисан шат**
  (4 × 15, 90 с амралт, нарийн шалгуур). Карт бүр дээр өвдөг, тохойн өнцгийн босго бичигдсэн.
- Хуучин нүүр хуудас **Тохиргоо** болж, «Нарийвчилсан тохиргоо» товч эсвэл зүүн цэсээр нээгдэнэ. Дасгал
  дуусахад эсвэл гарахад «Эхлэл» рүү буцна.
- «Дасгалыг автоматаар таних» унтраалгыг хассан (санамсаргүй дасгал солигдох шалтгаан болдог байсан).
  Өмнөх хувилбарын `settings.json`-д асаалттай байсан бол нэг удаа унтарна. Командын мөрөнд `--auto` хэвээр.

**Нэршил**
- Аппын нэр **Ухаалаг дасгалжуулагч**. Push-up = **Шалнаас түлхэлт**, шалгуурын түвшин **Уян / Стандарт /
  Нарийн**, «Техникийн шалгуур», «Техникийн алдаа». Дасгалын үеийн сонгогч, түүхийн шүүлтүүр, график «Суулт /
  Түлхэлт» болсон.

**Татаж ажиллуулах файл (Python хэрэггүй)**
- GitHub Releases-д Windows (`.zip`), macOS Apple Silicon ба Intel (`.app`), Linux (`.tar.gz`) бэлэн файл.
  `v` үсгээр эхэлсэн tag push хийхэд `.github/workflows/release.yml` гурван систем дээр PyInstaller-ээр угсарч,
  `--self-test`-ээр шалгаад байршуулна. Угсрах тохиргоо `packaging/ukhaalag.spec`.
- Бэлэн файлаас ажиллахад тохиргоо, түүх хэрэглэгчийн хавтсанд хадгалагдана (`form_checker/paths.py`):
  Windows `%APPDATA%`, macOS `~/Library/Application Support`, Linux `~/.local/share`. Эх кодоос ажиллуулахад
  өмнөх шигээ аппын хавтсанд.
- `python gui.py --self-test`: загвар, дуу, MediaPipe, OpenCV, цонхны сан ачаалагдаж буйг цонх нээлгүйгээр шалгана.

**Тест:** 86 (шинэ: эхлэх урсгал, автомат танилт нэг удаа унтрах, хэрэглэгчийн хавтасны зам).

## 2.2 — Цагаан, минимал интерфейс

- Анхдагч өнгө нь цагаан: цагаан дэвсгэр, нимгэн саарал хүрээ, хар үндсэн товчлуур («Эхлэх», «Дуусгах»).
  Өнгийг зөвхөн утгатай газар хэрэглэнэ: ногоон = зөв, улаан = алдаатай, шар = анхааруулга.
- Сонголтын товчлуур саарал зам дээрх цагаан таблет, гулсуур ба унтраалга хар-цагаан. Зүүн цэсийг нимгэн
  зураас тусгаарлаж, «Таны явц» хүрээгүй энгийн бичиг болсон. Алхмын дугаар, сонгосон дасгалын карт хар-цагаан.
- Дасгалын шатны шошго (Бэлтгэл, Дасгал, Дууссан) зөөлөн өнгөтэй. Видеоны эргэн тойрон цайвар саарал, шалгах
  жагсаалт, «Дасгалаа дуусгах уу?» асуулт, камерын алдааны мэдэгдэл цагаан карт болсон.
- Дүрсүүд, аппын дүрс, хөдөлгөөний графикийн шугам хар өнгөтэй. Шар бичгийг (анхааруулга, оноо 60–79) цагаан
  дэвсгэр дээр уншигдахаар бараан шар болгосон.
- Харанхуй горим хэвээр (зүүн цэсний «Өнгөний горим»), мөн хар-цагаан хэв маягтай. Өмнөх хувилбарын
  `settings.json`-д хадгалагдсан харанхуй горим нэг удаа цагаан болно; дахин сонговол хадгалагдана.
- Танилцуулгад «бүтэн дэлгэц F11» гэснийг «F» болгож зассан.

**Тест:** 83 (шинэ: хуучин тохиргооны файл цагаан загвар руу нэг удаа шилжих). CustomTkinter 5.2.2 ба 6.0.0
хоёуланд шалгасан.

## 2.1 — Windows, macOS, Linux дээр ажиллах, интерфейсийн сайжруулалт

**Эхлүүлэх**
- `start_windows.bat` (Windows) ба `start.sh` (macOS, Linux): анх удаа `.venv` үүсгэж, сангуудыг суулгаад
  аппыг нээнэ; дараагийн удаа шууд нээнэ. Python-ий хувилбар (3.10+, 64-bit), tkinter, Linux-д libEGL байгаа
  эсэхийг шалгаж, юу дутууг монголоор хэлнэ. Эвдэрсэн `.venv`-ийг өөрөө дахин үүсгэнэ.
- README-д Windows, macOS, Linux тус бүрийн алхам алхмаар заавар, асуудал гарвал юу хийхийг бичсэн.

**Үйлдлийн систем бүрт**
- Камер: системд тохирох OpenCV backend-ийг дарааллаар оролдоно (Windows: DirectShow → Media Foundation,
  macOS: AVFoundation, Linux: V4L2) ба эхний кадр иртэл хүлээнэ. Нээгдэхгүй бол тухайн системийн зөвлөгөө
  (камерын зөвшөөрөл, `video` бүлэг гэх мэт) гарна.
- Хавтасны замд кирилл үсэг эсвэл зай байхад MediaPipe загвар ачаалагдахгүй байсныг зассан (загварыг санах
  ойгоор өгнө). Тиймээс «Хүн компьютерын харилцаа» гэх мэт хавтсанд шууд ажиллана.
- Linux: Debian/Ubuntu, Fedora, Arch-ын кирилл фонтыг (DejaVu, Noto, Liberation, fontconfig) олно; дууг
  `paplay`, `pw-play` эсвэл `aplay`-аар тоглуулна; libEGL байхгүй бол ойлгомжтой мессеж гарна.
- macOS: Cmd+Q-ээр хаахад камер зөв хаагдаж, тохиргоо хадгалагдана; Terminal-аас нээхэд цонх урд гарна;
  бүтэн дэлгэцийг `F` товчоор (F11-ийг macOS ихэвчлэн өөртөө ашигладаг).
- Графикууд (хөдөлгөөн, дүн, түүх) зөвхөн Windows-д байдаг «Segoe UI»-ийн оронд аппын фонтыг ашиглаж,
  Windows-ийн томруулалт болон «Хэмжээ» тохиргооны дагуу бусад элементтэй адил томорно.
- 1366×768, 125% томруулалттай зөөврийн компьютер дээр цонх дэлгэцээс том болохоо больсон.
- Гаралтыг файл руу чиглүүлэх эсвэл «ө, ү» үсэггүй кодлолтой консолд (Windows) `print` алдаа өгч апп
  унадаг байсныг зассан: тэр үсгийг «?» болгоно.

**Интерфейс**
- Нүүр хуудас 3 алхамтай: 1) Дасгал, 2) Зорилго, 3) Эх үүсвэр ба тохиргоо. Доод талын **Эхлэх** самбар цонх
  намхан байсан ч үргэлж харагдаж, юу сонгосныг товч харуулна («Суулт · 3 сет × 10 давталт · вэбкамер 0»).
- Зөвхөн сонгосон эх үүсвэрийн тохиргоо харагдана. Вэбкамерт **Камер хайх** товч ажиллаж буй камеруудыг
  олж жагсаана. Идэвхгүй болсон тохиргооны дэргэд яагаад идэвхгүйг бичнэ.
- Зүүн цэсэнд **Хэмжээ** (80–200%): Linux-ийн өндөр нягтралтай дэлгэц, жижиг дэлгэцтэй компьютерт.
  Сонгосон хэмжээ хадгалагдана.
- Давталт тоологдоход тоолуурын карт ногоон (зөв) эсвэл улаан (алдаатай) болж гэрэлтэнэ.
- Идэвхгүй товчлуурууд бүдэг харагдана; түүхийн хүснэгт мөр алгасан дэвсгэртэй; нарийн цонхонд дасгалын
  картууд зургаа нууж, бичгээ ороож багтана; цонхны болон taskbar-ын дүрс.
- CustomTkinter-ийн алдааг зассан: хэмжээ солигдоход (эсвэл Windows-д өөр томруулалттай дэлгэц рүү цонхоо
  чирэхэд) нуусан хуудас, товчлуур дахин гарч ирээд давхцдаг байсан (`form_checker/gui/ctk_fixes.py`).

**Тест:** 82 автомат тест (2.1-д 10 шинэ: камерын backend, кирилл замтай загвар, «Хэмжээ» тохиргоо,
томруулахад нуусан элемент гарч ирэхгүй байх, камер хайх, давталтын гэрэл).

**Туршсан орчин:** Ubuntu 24.04, Python 3.12, mediapipe 1.2.0 (бүх тест, `start.sh`-ээр хоосон хавтаснаас
суулгаж ажиллуулах, цонхыг 100% ба 150%, 1100×660-аас 1980×1230 хүртэлх хэмжээнд). Windows, macOS-д
зориулсан хэсгүүдийг (камерын backend, зөвшөөрөл, Cmd+Q, `start_windows.bat`) кодонд тусгасан боловч тэр
системүүд дээр 2.1-ийг шууд туршаагүй.

## 1.4 — Хэрэглэгчийн туршлага

Анх нээхэд 3 алхамтай **танилцуулга**; дасгал эхлэхийн өмнө видеон дээр **шалгах жагсаалт** (камер харж
байна ✓, бүтэн бие ✓, эхлэх байрлал ✓, 1 секунд барих) тул тоолол яагаад эхлэхгүй байгааг шууд харна;
зорилтот гүнд хүрэхэд **богино «бип» дуу**; **Эхлэгч / Дунд / Ахисан** бэлэн зорилго; давталт хийсний дараа
`Esc` дарвал **дүнгээ харах эсэхийг асууна**; дүнгийн хуудсанд **өмнөх дасгалтай харьцуулалт** ба шинэ дээд
амжилт; камер нээгдэхгүй бол нэг товчоор **демо горимоор туршиж үзэх**.

## 1.3

Видеоны доор **хөдөлгөөний бодит цагийн график** (өвдөг/тохойн өнцөг, зорилтот бүс, давталт бүрийн
ногоон/улаан цэг), **бүтэн дэлгэц**, өнгөрсөн хугацаа, эхлэх байрлалын зураг, зүүн цэсэнд **«Таны явц»**
(сүүлийн дасгал, 7 хоногийн дүн), түүхэнд Squat/Push-up **шүүлтүүр**, цайвар горимд уншигдахуйц товчлуурууд,
жижиг дэлгэц (эсвэл Windows-ийн томруулалт) дээр цонх автоматаар багтана.

## 1.2

Товчлуур, цэстэй **цонхтой интерфейс** (`gui.py`): дасгал ба зорилгоо хулганаар сонгох, видеоны хажууд том
тоолуур ба зөвлөмж, давталт бүрийн графиктай дүн, өмнөх дасгалуудын **түүх**, заавар, харанхуй/цайвар өнгө,
камергүй **демо горим**. Тохиргоо дараагийн удаа хадгалагдаж үлдэнэ.

## 1.1

Кадрт бүтэн багтах заавар («Хөл харагдахгүй байна...»), 3-2-1 тоолол, дуут дохио, сет ба амралтын таймер,
дасгалын төгсгөлийн дүнгийн дэлгэц.

## 1.0

Squat ба push-up-ийг вэбкамераар шалгах анхны хувилбар (командын мөр, OpenCV цонх).
