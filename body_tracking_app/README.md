# Дасгалын хэлбэр шалгагч (Body Tracking Form Checker)

Вэбкамераар хүний дасгал хийж буйг бодит хугацаанд харж, **зөв хийж байна уу, үгүй юу**
гэдгийг дэлгэцэн дээр шууд харуулдаг апп. Эхний хувилбар **суулт (squat)** ба
**гар дээр суниалт (push-up)** гэсэн 2 дасгалыг шалгана.

- Биеийн 33 цэгийг Google MediaPipe Pose Landmarker загвараар илрүүлнэ.
- Үе мөчний өнцгөөр давталт тоолж, давталт бүрийг "зөв / алдаатай" гэж үнэлнэ.
- Алдаа гарвал юуг засахыг монголоор хэлж, тухайн үеийг улаанаар тэмдэглэнэ.
- **1.1 хувилбарт нэмэгдсэн:** кадрт бүтэн багтах заавар ("Хөл харагдахгүй байна..."), 3-2-1 тоолол,
  дуут дохио, сет ба амралтын таймер, дасгалын төгсгөлийн дүнгийн дэлгэц.
- **1.2 хувилбарт нэмэгдсэн:** товчлуур, цэстэй **цонхтой интерфейс** (`gui.py`): дасгал ба зорилгоо
  хулганаар сонгох, видеоны хажууд том тоолуур ба зөвлөмж, давталт бүрийн графиктай дүн, өмнөх дасгалуудын
  **түүх**, заавар, харанхуй/цайвар өнгө, камергүй **демо горим**. Тохиргоо дараагийн удаа хадгалагдаж үлдэнэ.
- **1.3 хувилбарт нэмэгдсэн:** видеоны доор **хөдөлгөөний бодит цагийн график** (өвдөг/тохойн өнцөг, зорилтот
  бүс, давталт бүрийн ногоон/улаан цэг), **бүтэн дэлгэц (`F11`)**, өнгөрсөн хугацаа, эхлэх байрлалын зураг,
  зүүн цэсэнд **«Таны явц»** (сүүлийн дасгал, 7 хоногийн дүн), түүхэнд Squat/Push-up **шүүлтүүр**, цайвар
  горимд уншигдахуйц товчлуурууд, жижиг дэлгэц (эсвэл Windows-ийн томруулалт) дээр цонх автоматаар багтана.
- **1.4 хувилбарт нэмэгдсэн (хэрэглэгчийн туршлага):** анх нээхэд 3 алхамтай **танилцуулга**; дасгал эхлэхийн
  өмнө видеон дээр **шалгах жагсаалт** (камер харж байна ✓, бүтэн бие ✓, эхлэх байрлал ✓, 1 секунд барих) тул
  тоолол яагаад эхлэхгүй байгааг шууд харна; зорилтот гүнд хүрэхэд **богино «бип» дуу** (push-up хийхдээ
  дэлгэц харахгүй ч мэдэнэ); **Эхлэгч / Дунд / Ахисан** бэлэн зорилго; давталт хийсний дараа `Esc` дарвал
  **дүнгээ харах эсэхийг асууна**; дүнгийн хуудсанд **өмнөх дасгалтай харьцуулалт** ба шинэ дээд амжилт; камер
  нээгдэхгүй бол нэг товчоор **демо горимоор туршиж үзэх**.
- **2.0 хувилбар (нээлттэй эхийн төслүүдээс суралцсан):** ижил төстэй 5 төслийг судалж ([CREDITS.md](CREDITS.md)),
  тэдний илүү шийдлүүдийг өөрийн кодонд оруулсан:
  - **1€ шүүлтүүр** (Casiez нар, CHI 2012): өнцгийн чичиргээ ~2 дахин багасч, их шуугиантай үед давталт
    илүү тоолох алдаа эрс буурсан (`tools/evaluate_filters.py`-аар хэмжинэ);
  - **Шалгуурын түвшин — Зөөлөн / Энгийн / Хатуу** (LearnOpenCV-ийн beginner/pro санаа): гүн, их биеийн хазайлт,
    хэмнэлийн босго түвшнээс хамаарна;
  - **Давталт бүрийн 0–100 оноо** ба **сануулга**: хэт хурдан давталт, squat-ын хөлийн байрлал (Exercise-Correction
    төслийн хөл/мөрний харьцаа). Сануулга давталтыг «алдаатай» болгохгүй, зөвхөн оноог бууруулна;
  - **Дасгалыг автоматаар таних**: суниалтын байрлалд орвол push-up, босвол squat руу өөрөө шилжинэ (Google ML Kit-ийн
    EMA тэгшитгэл ба орох/гарах хоёр босго);
  - **Идэвхгүй байдал**: сетийн дундуур 5 секундээс удаан камерын өмнөөс гарвал түр зогсоно, 15 секунд хөдөлгөөнгүй
    байвал «Амарч байна уу?» гэж сануулна (LearnOpenCV-ийн inactivity timer);
  - видеон дээр **үений өнцгийг нумаар** харуулж, доод цэгт хүрэхэд ногоон болгоно.

## 1. Суулгах (VS Code дээр)

1. **Python 3.11 эсвэл 3.12** суулгана: https://www.python.org/downloads/
   (Windows дээр суулгахдаа *"Add python.exe to PATH"*-ийг заавал чагтална.)
2. **VS Code**-ийг нээгээд Extensions (Ctrl+Shift+X) хэсгээс **Python** (Microsoft) өргөтгөлийг суулгана.
3. `File → Open Folder...` → `Хүн компьютерын харилцаа ICSI440\body_tracking_app` хавтсыг нээнэ.
4. `Terminal → New Terminal` цэсээр терминал нээгээд дараах командуудыг ажиллуулна:

   **Windows:**
   ```
   py -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```
   **macOS / Linux:**
   ```
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   ```
5. `Ctrl+Shift+P` → **Python: Select Interpreter** → `.venv` гэсэн Python-ийг сонгоно.

> **Өмнөх хувилбар суулгасан бол** `requirements.txt`-ийг дахин суулгана уу (4-р алхмын 2 дахь мөр):
> цонхтой интерфейсэд `customtkinter` сан нэмэгдсэн.

### 2.1 Цонхтой интерфейс (`python gui.py`)

Терминалаас: `python gui.py` (`.venv` идэвхтэй үед). Анх нээхэд 3 алхамтай танилцуулга гарна (дараа нь
**Заавар → Танилцуулгыг дахин үзэх**). Цонх 5 хуудастай:

| Хуудас | Юу байдаг |
|---|---|
| **Дасгал** (нүүр) | Squat / Push-up карт (зураг, юуг шалгадаг, камерыг хаана тавих), зорилго (**Эхлэгч / Дунд / Ахисан** бэлэн сонголт эсвэл давталт, сет, амралтыг өөрөө; чөлөөт горим), эх үүсвэр (вэбкамер / видео файл / демо), загвар (хурдан / нарийн), **шалгуур (Зөөлөн / Энгийн / Хатуу)**, **дасгалыг автоматаар таних**, дуу ба толин дүрс. **Эхлэх ▶** (эсвэл `Enter`) |
| **Дасгал хийх үед** | Эхлэхийн өмнө видеоны зүүн дээд буланд **шалгах жагсаалт** (юу дутуу байгаа нь шар «›»). Зүүн талд камер ба араг яс, түүний доор **хөдөлгөөний график** (сүүлийн 10 секундын өвдөг/тохойн өнцөг; ногоон бүс = зорилтот гүн, цэг = давталт, ногоон зөв, улаан алдаатай). Баруун талд: том тоолуур (5 / 10), сет ба өнгөрсөн хугацаа, давталт бүрийн ногоон/улаан цэг, сүүлийн давталтын **оноо**, гүний заагч (зорилгод хүрвэл ногоон), одоогийн зөвлөмж (эхлэх үед зөв байрлалын зураг), товчлуурууд |
| **Дүн** | Нийт/зөв давталт, нарийвчлал, **дундаж оноо** ба хэмнэл, **өмнөх ижил дасгалтай харьцуулалт** (▲/▼, шинэ дээд амжилт), **давталт бүрийн гүний график** (хулганаа аваачвал дэлгэрэнгүй), "Юуг сайжруулах вэ" жагсаалт (алдаа улаан, сануулга шар) |
| **Түүх** | `logs/` дахь бүх дасгал: нийт тоо, сүүлийн 14 дасгалын график, хүснэгт (2.0-оос дундаж оноотой). Дээд талын **Бүгд / Squat / Push-up** шүүлтүүрээр нэг дасгалыг тусад нь харна |
| **Заавар** | Камер байрлуулах, товчлуур, асуудал гарвал юу хийх |

Дасгал хийх үеийн товчлуурууд: `Space` = 3-2-1 эсвэл амралтыг алгасах, `P` = түр зогсоох,
`S` = дуу, `M` = толин дүрс, `E` = дуусгаж дүн харах, `1`/`2` = squat/push-up, `Esc` = гарах (давталт хийсэн
бол «Үргэлжлүүлэх / Нүүр хуудас руу / Дүнгээ харах» гэж асууна).
`F11` = бүтэн дэлгэц (хаана ч ажиллана; бүтэн дэлгэцээс `F11` эсвэл `Esc`-ээр гарна).

Зүүн цэсний **«Таны явц»** картад сүүлийн дасгал ба сүүлийн 7 хоногийн дүн харагдана; дээр нь дарвал Түүх нээгдэнэ.

Камергүй үед эсвэл хичээл дээр үзүүлэхдээ **Демо (камергүй)** эх үүсвэрийг сонгоно: зохиомол хүн зөв ба
алдаатай давталт хийж, апп яг камертай үеийнх шигээ тоолж, үнэлнэ.
Сүүлд сонгосон тохиргоо `settings.json`-д хадгалагдана (устгавал анхдагч утга руу буцна).

### 2.2 Командын мөрийн хувилбар (`main.py`)

Терминалаас (`.venv` идэвхтэй үед):
```
python main.py                       # squat, вэбкамер 0, 3 сет x 10 давталт, 60 с амралт
python main.py --exercise pushup     # push-up
python main.py --reps 15 --sets 2 --rest 90   # өөр зорилго
python main.py --reps 0              # чөлөөт горим (зорилго, амралтгүй)
python main.py --mute                # дуут дохиогүй
python main.py --source video.mp4    # видео файл
python main.py --source demo         # камергүй демо
python main.py --model full          # илүү нарийвчлалтай, арай удаан загвар
python main.py --save result.mp4     # дүнг видео болгон хадгалах
python main.py --lang en             # англи текст
python main.py --level strict        # шалгуур: easy (зөөлөн) / normal (энгийн) / strict (хатуу)
python main.py --auto                # дасгалыг (squat / push-up) автоматаар таних
```

**Товчлуурууд:** `1` = squat, `2` = push-up, `Space` = 3-2-1 тоолол эсвэл амралтыг алгасах,
`S` = дуу асаах/унтраах, `E` = дасгалыг дуусгаж дүн харах, `R` = шинээр эхлэх, `M` = толин дүрс,
`Q`/`Esc` = гарах.

Хоёр хувилбар хоёулаа дасгалын дараа давталт бүрийн мэдээллийг сетийн дугаартайгаа
`logs/session_*.csv` файлд хадгална (аппын хавтас дотор). Түүх хуудас эдгээр файлаас уншина.

### Дасгал хэрхэн явагддаг вэ

1. **Эхлэх:** камерын өмнө зогсоход програм биеийн аль хэсэг харагдахгүй байгааг хэлнэ
   ("Хөл харагдахгүй байна. Камераас холдож зогс" гэх мэт). Кадрын хүрээ улбар шар байна.
2. Бүтэн харагдаж, эхлэх байрлалдаа (squat: шулуун зогсох, push-up: гараа тэнийлгэх) орвол хүрээ ногоон
   болж, дугуй цагираг дүүрнэ. **1 секунд** хөдөлгөөнгүй барина.
3. **3-2-1** гэж тоолоод "Бэлэн. Эхэл!" гэнэ. Үүнээс өмнө хийсэн хөдөлгөөн тоологдохгүй.
4. **Дасгал:** давталт бүрийн дараа дуут дохио гарна: өсөх 2 ая = зөв, буух намхан 2 ая = алдаатай.
   Давталт бүр ногоон/улаан цэгээр харагдана (`main.py`-д зүүн дээд, цонхтой интерфейсэд баруун талын самбарт).
5. Сетийн зорилгод хүрэхэд **амралтын таймер** гарна (`Space` = алгасах). Дараа нь 1-р алхмаас давтана.
6. Бүх сет дуусахад (эсвэл `E` дарахад) **дүнгийн дэлгэц**: нийт/зөв давталт, сет бүрийн цэгүүд,
   хамгийн их гарсан алдаа ба зөвлөмж.

Видео файл шалгахад тоолол, сетгүйгээр бүх давталтыг шууд тоолно.

## 3. Камерыг хэрхэн байрлуулах вэ

- Камераас **2–3 метр** зайд зогсож, **толгойноос хөл хүртэл** бүтэн харагдах ёстой.
- **Squat:** хажуугаараа зогсвол хамгийн нарийн (өвдөг, их бие, өсгий шалгана).
  Урдаас зогсвол өвдөг дотогш орж байгааг шалгана (гүнийг 3D цэгээр тооцно).
- **Push-up:** заавал **хажуугаас** харагдах ёстой. Камерыг шалнаас 30–60 см өндөрт тавина.
- Гэрэлтүүлэг сайн, ар тал энгийн байвал илүү тогтвортой ажиллана.

## 4. Юуг шалгадаг вэ

| Дасгал | Шалгах зүйл | Босго (form_checker/config.py) |
|---|---|---|
| Squat | Гүн: өвдөгний өнцөг ≤ 100° | `depth_angle` |
| Squat | Их бие урагш хэт хазайх > 50° | `max_torso_lean` |
| Squat | Өвдөг дотогш орох (урдаас) | `min_knee_ankle_ratio` |
| Squat | Өсгий газраас салах (хажуугаас) | `max_heel_lift_ratio` |
| Squat | Давталтын хооронд бүрэн босоогүй | `rebound_*` |
| Push-up | Гүн: тохойн өнцөг ≤ 90° | `depth_angle` |
| Push-up | Бэлхүүс унжих / бөгс өргөх: мөр-хонго-шагай < 160° | `min_body_line` |
| Push-up | Дээд байрлалд гараа бүрэн тэнийлгээгүй | `rebound_*` |

Босгуудыг `form_checker/config.py` файлд өөрчилж аппыг илүү хатуу эсвэл зөөлөн болгож болно.

**Шалгуурын түвшин (2.0).** Нүүр хуудасны «Шалгуур» эсвэл `--level`. Хүснэгтийн утгууд «Энгийн» түвшнийх:

| | Зөөлөн | Энгийн | Хатуу |
|---|---|---|---|
| Squat гүн (өвдөг ≤) | 110° | 100° | 90° |
| Squat их биеийн хазайлт (<) | 55° | 50° | 45° |
| Push-up гүн (тохой ≤) | 100° | 90° | 80° |
| Push-up биеийн шугам (>) | 155° | 160° | 165° |
| Хэт хурдан гэх хугацаа (squat / push-up) | 0.7 / 0.5 с | 1.0 / 0.8 с | 1.2 / 1.0 с |
| Хөлийн хуруу / мөрний харьцаа (squat, урдаас) | ≥ 0.75 | ≥ 0.9 | ≥ 1.2 |

**Давталтын оноо (2.0).** 100-аас: хэлбэрийн алдаа бүр −20, бүрэн босоогүй/тэнийлгээгүй −15, гүехэн −15…−45
(дутуу градус бүр −1), сануулга бүр (хэт хурдан, хөлийн байрлал) −10. Сануулга давталтыг «алдаатай» болгохгүй.

## 6. Асуудал гарвал

- **Камер нээгдэхгүй:** Zoom/Teams зэрэг камер ашиглаж буй програмыг хаа. Өөр камер бол `--source 1`.
  macOS дээр *System Settings → Privacy & Security → Camera* хэсэгт VS Code-д зөвшөөрөл өгнө.
- **`models/` хавтсанд загвар байхгүй:** эхний удаа ажиллуулахад интернэтээс автоматаар татна.
- **Удаан ажиллаж байна:** `--model lite` (анхдагч) ашиглаж, `--width 640 --height 480` гэж бууруул.
- **Дуу гарахгүй:** компьютерийн дууны түвшинг шалгаж, `S` товч дарж үзнэ (зүүн дээд самбарт "дуу: асаалттай"
  гэж харагдах ёстой).
- **Тоолол эхлэхгүй байна:** видеон дээрх шалгах жагсаалтын шар «›» тэмдэгтэй мөрийг харна (жишээ нь
  «Бүтэн бие кадрт багтсан» бол камераас холдоно). Бүгд ✓ болоод 1 секунд хөдөлгөөнгүй зогсоход эхэлнэ.
  Шууд эхлэх бол `Space` дарна.
- **`gui.py` ажиллахгүй, "No module named customtkinter":** `requirements.txt`-ийг дахин суулгана
  (`.venv\Scripts\python -m pip install -r requirements.txt`). "No module named tkinter" бол Python-ийг
  python.org-оос суулгахдаа *tcl/tk and IDLE* сонголтыг идэвхтэй үлдээнэ.
- **Цонх хэт том/жижиг:** дэлгэц жижиг бол цонх өөрөө багтаж нээгдэнэ, баруун талын самбар нягт болно. Цонхыг
  чирж томруулах эсвэл `F11` дарж бүтэн дэлгэцээр ашиглаж болно.
- **Дасгал өөрөө солигдоод байна:** нүүр хуудсанд «Дасгалыг автоматаар таних»-ыг унтраана. Гараар сонгосон
  дасгалыг байрлал өөрчлөгдөх хүртэл буцааж солихгүй.
- **Хэт хатуу / зөөлөн санагдаж байна:** нүүр хуудасны «Шалгуур»-аас өөр түвшин сонгоно.
- **Монгол үсэг дөрвөлжин харагдана:** кирилл фонт олдоогүй гэсэн үг; `fonts/` хавтас үүсгээд дурын кирилл
  дэмждэг `.ttf` фонт хуулна, эсвэл `--lang en`.
